Kinyarwanda Voice Assistant 🗣️🇷🇼
This project is a speech recognition tool tailored for the Kinyarwanda language. It leverages OpenAI’s Whisper model (via Hugging Face’s transformers library) to convert spoken Kinyarwanda into text. The goal is to promote digital inclusivity by making voice-based technology accessible to Kinyarwanda speakers.

✨ Key Capabilities
🗣️ Converts Kinyarwanda speech from audio input into text

🌐 Powered by the Whisper multilingual ASR model

🔧 Designed with flexibility for extending into voice-command systems or intent recognition
